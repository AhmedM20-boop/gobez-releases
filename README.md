# Gobez – Learn Amharic: Android releases

This repository holds only the Android app files (APKs) for **Gobez**, an Amharic course.

**Download Gobez from the website: https://gobezapp.net/download/**. The page shows the current version, its size, and the file's SHA-256 fingerprint so you can check the download.

Each release here is one app version. The file is named `gobez-<version>.apk` and is attached to the release tagged `v<version>`.

There is no source code here.
